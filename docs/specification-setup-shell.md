# 組み込み起動のセットアップ専用シェル（#607）

`embedded.start({ setupShell: { command, cwd? } })` で最初のペインを素のシェルとして開く。`setupPane` は Claude Code のスキル起動用なので別のオプションにする。`cwd` は実在する絶対ディレクトリ、省略時はホーム。`command` は空でない 1000 文字以下の単一行で、タブ以外の制御文字を許さない。

シェルのプロンプト出力を待ち、コマンドを PTY の入力欄へ書く。シェルがブラケット貼り付けを有効にした場合はその形式を使う。未対応シェルでは通常の入力とし、タブは quote-next で補完を抑える。Enter は送らず、利用者が内容を確認して実行する。プロンプトが確認できない場合も盲打ちしない。

この起動では前回ペインの復元、保持役の復元・新規作成、セットアップ状況の起動時確認・自動表示、設定済み追加ペインの作成、エージェントの自動起動、初期コマンドの自動送信を行わない。専用ペインは node-pty でログインシェルとして起動する。通常の起動と `setupShell` を渡さない組み込み起動は従来の経路を使う。起動引数・環境変数・HTTP API にこの指定口は作らない。
